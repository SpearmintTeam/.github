# Welcome
This is the **Spearmint Team** organization page, the people behind *Funkin': Spearmint*. The engine is still in its **early public stages**, meaning that the only person properly maintaining it at the moment is the owner. Because of this, please be patient when reporting issues and suggesting features.

# History
*Funkin': Spearmint* is built using [Heaps](https://heaps.io/), but it wasn't always like that. The engine was originally made with [HaxeFlixel](https://haxeflixel.com/) under the name *RevEngine*. It was mostly finished before the switch, so some of its code was reused in the rewrite.
